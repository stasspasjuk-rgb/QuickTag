# Changelog

## 1.0.0

- Скрытие ников игроков над головой через scoreboard teams.
- Shift + ПКМ по игроку показывает его настоящий ник в actionbar.
- Настройка сообщения через MiniMessage в `config.yml`.
- Команда `/quicktag reload`, право `quicktag.reload` (OP по умолчанию).
- Поддержка Paper/Purpur 26.2 и Java 25 без дополнительных плагинов.
- Автоматическая сборка и тесты в GitHub Actions.
